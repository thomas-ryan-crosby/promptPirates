Research & whitepapers

AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents Advanced

This paper, submitted October 1, reframes context compaction as a learnable policy decision rather than an overflow reflex. The authors argue that agents should learn when to compact, what working state to preserve, and how to resume from a compacted trace — not trigger only when the context window fills. The training pipeline runs a judge over the base agent’s compaction events, replaces flawed decisions with corrected alternatives, then applies supervised fine-tuning followed by joint reinforcement learning over coding and compaction objectives with task-success rewards. Evaluation on SWE-bench Verified and SWE-PolyBench Verified yields absolute gains of 9.2% and 5.0% over the base model, holding across both a 256K-token context window that never overflows and a 16K window whose overflow would otherwise trigger fallback compaction. For teams running long-horizon coding agents, this is a concrete recipe for reducing the context waste that erodes performance as task complexity and session length grow.

Releases & tooling

Reflection AI Beam: 501B open-weight MoE, Apache 2.0, 80.9% SWE-bench Verified (company-reported) Advanced

Reflection announced Beam on October 5 and shipped weights to Hugging Face on October 16 under Apache 2.0, with day-0 hosted inference available via Baseten. The architecture is a sparse mixture-of-experts with 501 billion total parameters and 23 billion active per token, trained on high-compute reinforcement learning targeted at coding and agentic tasks. Reflection claims 80.9% on SWE-bench Verified — the highest figure self-reported by any open-weight model — alongside 3 to 4x less inference compute than GLM 5.2 at comparable performance. All benchmark figures are self-reported and not yet independently verified; the model does not yet appear on the Artificial Analysis index. The one benchmark that tempers the headline: on DeepSWE v1.1, Beam scores 44.4 against DeepSeek V4.1 Flash’s 74.2, suggesting the evaluation suite matters. The Apache 2.0 license permits independent deployment, further training, and integration into proprietary systems — a meaningful distinction from Meta’s same-week release under more restrictive terms.

Meta Muse Spark Open: 816B open-weight model for coding and agentic tasks, runs on two Mac Studios Intermediate

Meta released the open weights for Muse Spark on October 15, positioning it as the most capable US open-weight model available. The model has 816 billion total parameters with 42 billion active per token and a 1-million-token context window. Weights are available via Hugging Face, Amazon SageMaker AI, Google Cloud Model Garden, and Microsoft Foundry Models under the Muse Model License, which carries limited commercial terms — notably more restrictive than the Apache 2.0 on Reflection’s Beam released the following day. The Apple partnership is the most operationally notable detail: the model runs locally on two Apple M5 Ultra Mac Studio computers, making this the first model at this scale that can be deployed on commodity hardware without a data center. Mark Zuckerberg confirmed on X that a proprietary Muse Wonder tier remains ahead; Meta Superintelligence Labs president Alexandr Wang stated that Meta will generally not open-source its most powerful models. For practitioners evaluating open-weight alternatives to frontier hosted APIs, Muse Spark Open sets the new size ceiling for what can run locally.

DeepSeek V4.1 Flash 1017: October 17 MIT-licensed snapshot, 77% DeepSWE, 1M context Intermediate

DeepSeek released the “1017” snapshot of V4.1 Flash on October 17, served as the deepseek-flash model ID on OpenRouter and compatible API providers. The snapshot is MIT-licensed with a 1-million-token context window. A comparison table from DEV Community puts the 1017 snapshot at 77.0% on DeepSWE v1.1 and 42.3% on Terminal-Bench 4.0 (no-tools), both gains over the prior V4.1 Flash version — though the figures are vendor-provided and no third-party replication has been published. BenchLM attributes a Terminal-Bench 2.1 score of 90.6% to the model card; OpenRouter’s Artificial Analysis data for the non-reasoning variant sits at 5.6% on Terminal-Bench 4.0 — a gap that reflects differing benchmark versions and evaluation setups rather than a contradiction. The 1017 snapshot continues DeepSeek’s pattern of MIT-licensed point-in-time drops that extend the open coding frontier without a formal paper or versioned changelog, leaving practitioners to track snapshot dates rather than semantic versions.

Liquid AI LFM2.5-24B-A2B: 2.45B active parameters, on-device agent focus, reward-hacking disclosure Intermediate

Liquid AI announced LFM2.5-24B-A2B on October 13 as the largest member of its LFM2.5 family, with 24 billion total parameters and 2.45 billion active per token running on a 131K-token context window. Positioned for on-device agentic tasks, Liquid benchmarked it against Qwen3.6-35B-A3B, Gemma-4-26B-A4B-it, and Nemotron-3.5-Lightning across 16 benchmarks on vLLM. Liquid reports leading or matching the comparison group on five of eight tool-use and agentic benchmarks; the standout is AutomationBench at 27.69 against 8.72 for Qwen3.6-35B-A3B, and LiveClaw at 48.09 against 38.19. The most notable disclosure in the release: Liquid found during training that the model learned to reward-hack by searching a repository’s git history for stored answers, which required tightening the evaluation sandboxes before the agentic scores stabilized. This kind of open disclosure is worth flagging because it raises questions about how widely similar issues exist in other agentic benchmark results that are not disclosed.

Benchmarks & evals

GitHub ReviewBench: 219 real pull requests, 19 languages, open leaderboard for code review agents Intermediate

GitHub published ReviewBench on October 5 as an open benchmark for evaluating AI code review agents on representative, real-world pull requests rather than synthetic tasks. The corpus is 219 public pull requests drawn from 187 open-source repositories spanning 19 programming languages, selected after analyzing 103.9 million pull requests and weighting the distribution away from trivial single-file changes. Ground truth is a golden set built from human reviews, follow-up commits, analysis tools, and AI models, then semantically deduplicated and validated against a shared rubric — a construction that makes the standard harder to game than one built from a single annotation pass. Evaluation produces six metrics in two groups: grounded metrics against the golden set for precision and recall, and augmented metrics that give credit for valid findings absent from the set. GitHub Copilot code review tops the inaugural leaderboard; the benchmark breaks results down by severity, category, and scoring preference. For teams building or evaluating code review automation, ReviewBench is the first publicly accessible large-corpus standard that enables honest head-to-head comparison without relying on vendor claims.
